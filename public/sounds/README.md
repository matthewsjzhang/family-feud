# Recorded sound effects

Put audio files here to replace the game's synthesized sounds on the game board:

| File | Replaces |
|---|---|
| `strike.mp3` | The wrong-answer / strike buzzer (strikes, face-off misses, failed steals) |

If a file is missing or can't be played, the synthesized sound is used instead.

Audio files in this folder are **not committed** (see `.gitignore`), because recordings from the TV show are copyrighted. Each copy of the game needs its own files.
